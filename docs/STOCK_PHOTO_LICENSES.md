# 스톡 사진 사이트 라이선스 판정 (Unsplash · Pexels · Pixabay · Freepik · Burst)

> 작성: 리스크 담당(legal-reviewer) · 확인일 **2026-10-02** · 대표 지시(2026-10-02) "Unsplash 라이선스 허용 여부 — 5개 사이트 표 참고해서 판정"
> **법률 자문 아님 · 추정.** 아래 판정은 공개 약관을 읽은 리스크 담당의 추정이며, 협찬 계약 분쟁 등 실제 사안은 변호사 확인이 필요하다.
> **적용 상태: 초안.** 디자인 시스템 §9-2는 아직 "CC0 · CC BY · 공공누리 제1유형"만 허용한다. 아래 개정안(§3)은 대표 결정(§5 L1~L3) 후에만 반영한다.

용도 전제: 인스타 카드뉴스 "책가도 노트"(협찬·광고 게시물 포함 = **상업적 사용**), 크롭·톤 편집·원화 프레임과 콜라주(2차 가공), 유튜브 썸네일·숏폼 재사용 가능, 마지막 장 출처 줄(§8-4) 운영.

## 3. 디자인 시스템 §9-2 개정안 (v1.4 초안, 대표 결정 후 적용)

L1=ⓑ(+Unsplash·Pexels·Pixabay) 가정 예시. ⓒ·ⓓ 선택 시 해당 행만 추가.

```diff
 **9-2. 사진 편집 프리셋 (순서 고정)**
 ...
-- 사진 조건: CC0 · CC BY · 공공누리 제1유형, 얼굴·로고·브랜드 포장·읽히는 글자 없음.
+- 사진 조건: CC0 · CC BY · 공공누리 제1유형 · Unsplash License · Pexels License · Pixabay Content License
+  (L1 결정 범위만), 얼굴·로고·브랜드 포장·읽히는 글자 없음.
+- 스톡 자체 라이선스 사진은 **반드시 편집본**(원본 무편집 금지 = 각 사이트 "unaltered/without significant
+  modification 판매 금지" 조항 대응). Unsplash+·editorial-only·사이트가 AI 생성 표시한 항목은 쓰지 않는다(L3 결정 전).
+- 스톡 사진을 생성형 AI의 입력·학습·참조 이미지로 쓰지 않는다(Unsplash·Freepik 약관 AI/ML 금지).
+- 레코드에 다운로드 시점 라이선스 증거(`site, license_name, license_url, downloaded_at, author, page_url,
+  release_status`)가 없으면 렌더를 거부한다(docs/STOCK_PHOTO_LICENSES.md §4).
```

§8-4 출처 줄 추가 행(사이트별 표기 예):

```diff
 - 실사 사진은 별도 줄 `사진: 작가 · 라이선스`(CC BY는 작가명+라이선스 필수).
+  - Unsplash: `사진: 작가 · Unsplash License`
+  - Pexels: `사진: 작가 · Pexels License`
+  - Pixabay: `사진: 작가 · Pixabay Content License`
+  - Freepik(L1=ⓒ 이상일 때만): `사진: 작가 · Freepik` (귀속 의무, 생략 시 렌더 거부)
+  - Burst(L1=ⓓ일 때만): `사진: 작가 · Burst (Shopify)`
+  - 여러 장이면 `/`로 이어 붙인다. PHOTOS.json에서 자동 생성.
```

## 4. PHOTOS.json 레코드 필수 필드 제안

라이선스가 나중에 바뀌어도 **다운로드 시점 조건**을 증명하기 위한 최소 필드. 하나라도 비면 렌더 거부.

| 필드 | 예 | 목적 |
|---|---|---|
| `site` | `unsplash` | 출처 사이트 |
| `license_name` | `Unsplash License` | 출처 줄 자동 생성 |
| `license_url` | `https://unsplash.com/license` | 약관 원문 위치 |
| `downloaded_at` | `2026-10-02T09:00:00+09:00` | 그 시점 약관 적용 근거 |
| `author` | 작가 표시명 | 출처 줄·귀속 |
| `page_url` | 사진 상세 페이지 | 항목 단위 확인 |
| `release_status` | `none_face0_logo0` / `model_release_on_file` / `unknown` | 인물·재산권 상태. `unknown`이면 얼굴 0·로고 0 확인 결과를 함께 기록 |

권장 추가: `ai_generated_flag`(사이트 표시값), `editorial_only`(Freepik), `license_snapshot`(약관 페이지 Wayback URL 또는 저장소 내 텍스트 사본 경로), `edit_preset`(§9-2 적용 내역).
