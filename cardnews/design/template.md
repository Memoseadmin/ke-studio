# 책가도 노트 카드뉴스 템플릿 v0.1 (인스타그램 캐러셀, 한국어)

> 작성 2026-10-02, designer. 렌더러: `cardnews/design/render_cards.py`(Pillow 목업, 이미지 생성 키 없음).
> 색·폰트·대비·금지 규칙은 채널 디자인 시스템 `episodes/EP001/design/design-system.md` v1.0 §1~§3·§6을 **그대로 참조**한다(복사·수정하지 않음).
> **4:5(1080x1350) 규격은 이 문서의 "제안"이다. 디자인 시스템 버전업(§ 추가)은 대표 승인 후 본 채널 HANDOFF "대표 결정 대기"를 거쳐서만 한다.**

## 1. 캔버스·안전 영역 (제안)

| 항목 | 값 |
|---|---|
| 캔버스 | 1080 x 1350 px, 4:5, sRGB, PNG |
| 안전 영역 | 사방 72px 안쪽(x 72~1008, y 72~1278). 글자·핵심 도형은 이 안에만 |
| 프로필 그리드 1:1 크롭 | y 135~1215. **헤드라인은 반드시 이 안에**(표지 헤드라인 블록 y 600~약 960) |
| 우하단 | 목업 단계에서는 `MOCKUP` 표기(red 외곽선, 30px). 게시 버전에서 제거 |
| 용량 | 장당 PNG-8(적응 256색) 약 70~100KB. `--rgb`로 24비트 저장 가능(장당 300~450KB) |

인스타 피드는 4:5를 자르지 않지만, 플랫폼 UI는 수시로 바뀌므로 게시 전 업로드 미리보기로 최종 확인한다(디자인 시스템 §4와 같은 원칙).

## 2. 색 토큰 (디자인 시스템 §1 그대로)

| 역할 | 토큰 | Hex |
|---|---|---|
| 배경 | `ke-paper` | #F7F3EA (+ 한지 결 9% 블렌드, 5단계 포스터라이즈) |
| 글자·선 | `ke-ink` | #111111 |
| 강조 블록(CTA·유형 태그) | `ke-red` | #C8102E, 위 글자는 `ke-white`(대비 5.9) |
| 시그니처 바·장 번호 알약·체크박스 | `ke-yellow` | #FFD23F, 위 글자는 `ke-ink`(대비 13.1) |
| 표 머리·단청 띠 바탕·산 실루엣 | `ke-night` | #1B1F2A |
| 모티프 보조(면적 15% 이하) | kraft #C9A877 · celadon #6FA89B · wheat #F2D49B | 글자에는 쓰지 않음 |

한 장 = 배경 paper 1색 + 강조 red 또는 yellow 1색이 지배. 금지 조합(yellow 글자/red 바탕, red 글자/night 바탕)은 렌더러에 아예 없다.

## 3. 타이포 (디자인 시스템 §2 폰트, 크기는 4:5 제안)

| 요소 | 폰트 | 크기 | 비고 |
|---|---|---|---|
| 표지 헤드라인 | Black Han Sans | 128px | 2줄 상한, ≤14자. 320px 축소 시 약 38px |
| 본문 헤드라인 | Black Han Sans | 88px | 2줄 상한. 축소 시 약 26px |
| CTA(마지막 장) | Black Han Sans | 84px | red 블록 위 white |
| 본문 | Pretendard Regular | 44px | 최대 3줄. 축소 시 약 13px |
| 표지 부제·출처 | Pretendard | 44 / 40px | 2줄 상한 |
| 장 번호(n/N) | Liberation Sans Bold(숫자) | 40px | yellow 알약 |
| 계정명·핸들·AI 고지 | Pretendard | 34~40px | 하한 34px(폰 가독) |

- 하한: **헤드라인 ≥72px, 본문 ≥40px**, 보조 ≥34px. 작은 글씨(≤30px)는 MOCKUP 표기 외 없음.
- 글자수 vs 줄수: 본문 60자는 44px에서 **3줄**(한 줄 약 20~22자). 2줄로 끝내려면 ≤44자. marketer 합의 "≤60자 2줄"은 44자 기준으로 쓰는 것을 권장(초과 시 렌더러가 경고만 출력하고 3줄로 그린다).
- 글꼴 대체 순서(자동, `fc-list`): KR 헤드라인 Black Han Sans → Pretendard Black/Bold → **WenQuanYi Zen Hei(현재 VM)** → Noto Sans CJK. 본문 Pretendard Regular → WenQuanYi → Noto CJK. 라틴 Liberation Sans Bold → DejaVu Sans Bold. Black Han Sans가 없으면 헤드라인에 크기/40 px 획 보강(가짜 볼드)을 건다. 설치는 `scripts/setup.sh`(COO) 결정.
- 화면 문구에 em dash 금지, 과장·낚시 문구 금지(§6-6·7).

## 4. 레이아웃 3종

모든 장은 같은 캔버스·여백·폰트. 글자는 전부 프로그램 오버레이. 레이어 순서: **배경(paper+한지 결) → 플레이트(모티프) → 텍스트 → MOCKUP**.

### 4-1. 표지 (1장)
```
y  72  [책가도 노트 ink 라벨]                  [유형 태그 red]
y 150  ┌ 플레이트 영역 936x410: 책가도 책장 격자(4x2칸, 책 묶음) ┐
y 560  └────────────────────────────────────────┘
y 600  ┌ paper 블록 + ink 6px 테두리 ───────────┐
       │  헤드라인 128px 1~2줄 (≤14자)            │
       └────────────────────────────────────────┘
       ▬ yellow 시그니처 바 320x14 (ink 2px)
       부제 44px 1~2줄 (cards[0].body)
y1228  @chaekgado.note 40px          ● ● ● (넘김 힌트)
```
- 책가도 격자는 계정 정체성(모든 표지 동일 자리). AI 플레이트가 생기면 같은 150~560 영역에 교체.

### 4-2. 본문 (중간 장) + 변형 2종
```
y  72  (n/N yellow 알약)                           책가도 노트
y 200  헤드라인 88px 1~2줄
       ▬ yellow 바 200x14
y ~330 본문 44px 최대 3줄        ← 변형 A 체크리스트 / 변형 B 비교표
y 760  ┌ 플레이트 영역 936x408: visual 키워드 → 플랫 모티프 ┐
y1168  └────────────────────────────────────────┘
y1228  @chaekgado.note 34px
```
- **변형 A 체크리스트**: `type":"체크리스트"`이고 body에 `·` 또는 줄바꿈이 있으면 자동(또는 `"layout":"checklist"`). 항목 최대 4개, yellow 체크박스 40px + ink 체크.
- **변형 B 비교표**: 카드에 `"table":[["머리1","머리2"],["a","b"],...]`(최대 4행 2열). 머리행 red/night 위 white, 본문행 paper 위 ink, 셀 높이 92px, 글자 44px 중앙.
- 플레이트 영역은 **고정 좌표**(72,760)~(1008,1168). `visual` 키워드 → 모티프 매핑: 책가도/책장/책 → 책장 격자 · 단청/띠/처마 → 단청 띠 · 달/산/십장생 → 달·산 실루엣 · 꽃/모란/화조 → 모란 · 한지/결/도장 → 한지 결+낙관 사각(글자 없음) · 그 외 → 책장 격자.
- `호랑이·까치`는 디자인 시스템 §6-3(KPop Demon Hunters 연상 "호랑이·까치 조수 모티프" 금지)에 걸리므로 **렌더러가 달·산으로 자동 대체하고 경고를 출력**한다. 인물·로고·캐릭터·드라마·배우·아이돌 키워드도 동일 처리. 과제 지시문의 "까치·호랑이 실루엣" 허용은 디자인 시스템과 충돌하므로 시스템 쪽을 따랐다(대표 결정 대기 항목).

### 4-3. 출처·CTA (마지막 장)
```
y  72  ┌ 플레이트 영역 936x160: 단청 띠(night 바탕, 반원 red/celadon/wheat 반복) ┐
y 232  └────────────────────────────────────────┘
y 320  ┌ red 블록 ────────────────────────────────┐
       │  CTA 84px white 중앙 "저장해 두고 다시 보기"  │
       └────────────────────────────────────────┘
       ▬ yellow 바 320x14 중앙
       출처 (48px 헤드) + 출처 1~2줄 40px (cards[-1].body 우선, 그다음 post.sources)
       [협찬 슬롯 wheat 박스, sponsor_slot 비어 있으면 생략]
y1158  이미지·초안은 AI로 생성, 사실 확인은 사람이 했습니다 (34px, 중앙)
y1222  @chaekgado.note 40px 중앙
```
- 광고 표기("#광고"/유료 파트너십 라벨)는 캡션 첫 줄이 담당(cardnews/docs/PLAN.md 협찬 규칙). 카드 안 협찬 슬롯은 자리 표시용이며 로고는 계약서에 사용 허락 조항이 있을 때만(렌더러는 로고를 그리지 않는다).

## 5. AI 플레이트 교체 규칙 (레이어 분리)

- `<post_dir>/plates/card-NN.png`가 있으면 해당 장의 플레이트 영역에 **그 파일을 그대로 리사이즈해 넣고** 도형 모티프를 그리지 않는다. 텍스트 레이어는 변하지 않는다.
- 플레이트 생성 프롬프트 접두(docs/TOOLING_TTS_IMAGE.md §D-3 고정): `Korean minhwa folk-painting style flat illustration, bold ink outlines, obangsaek palette ... textured hanji paper background, no text, no logos, no photorealism, no real person likeness` + 디자인 시스템 §5 네거티브 전부. 글자 없는 플레이트만.
- 플레이트 영역 비율: 표지 936x410(≈2.28:1), 본문 936x408, 마지막 936x160. 생성 시 같은 비율로 요청하거나 크롭 여유를 둔다.

## 6. 체크리스트 (게시 전, 장마다)

1. 헤드라인 ≤14자·2줄, 본문 ≤60자(권장 44자), 숫자에는 "추정" 또는 출처.
2. 320x400 축소(contact.png 타일)에서 헤드라인 판독 가능.
3. 인물 얼굴 0, 로고 0, IP 캐릭터 0, 드라마 스틸 0, 이미지 안 글자(오버레이 제외) 0. 호랑이·까치 모티프 0.
4. 건강·금융·법률·정치·실존 인물 비판 소재 아님(PLAN).
5. 마지막 장에 출처 1줄 + AI 고지 + 핸들. 협찬 게시물이면 캡션 첫 줄 "#광고".
6. 게시 버전은 MOCKUP 표기를 뺀 렌더로 교체(렌더러 옵션은 AI 플레이트 도입 시 추가 예정).
