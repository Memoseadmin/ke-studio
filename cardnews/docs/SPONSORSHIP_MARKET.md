# 카드뉴스 — 한국 협찬 시장·벤치마크 조사 (2026-10-02)

목적: 한국어 인스타 카드뉴스 계정(신규)으로 **한국 브랜드 협찬 수익**을 가장 빨리 내는 경로를 찾는다. 게이트 C1(90일) = 팔로워 2,000·저장률 3%·미디어킷·제안 5건 / C2(6개월) = 팔로워 1만·첫 유료 협찬.
표기: 모든 출처의 **확인일은 2026-10-02**(따로 적은 날짜 = 기사 날짜). 출처가 업체 블로그·검색 요약뿐이면 **추정치**로 적었다. "스니펫"은 instagram.com 검색 결과에 보이는 요약값이다. 언제 수집됐는지 알 수 없어 추정치로 취급한다(Instagram 직접 조회는 429 오류로 막힘). 실측값이 생기면 교체한다.

## 0. 요약 (먼저 읽을 것)
- **단가(추정치)**:
  - 1천~1만 팔로워는 제품 협찬, 많아야 원고료 5~10만원이다.
  - 1만은 피드 1건 10~30만원, 5만은 50~170만원, 10만은 100~700만원.
  - 업계 공식은 피드 "(팔로워÷1,000)×1만원"이다. 릴스는 피드보다 20~50% 비싸고, 2차 활용은 30~50%를 더 받는다.
- **가장 빠른 첫 현금 경로**: 지자체·관광재단 SNS 서포터즈(월 10~20만원, 팔로워 조건이 없거나 300명 우대)와 체험단 플랫폼(제품·포인트). 브랜드 직접 유료 협찬은 현실적으로 **팔로워 5천~1만 이후**다.
- **성장 레버**:
  - DM 공유(sends)가 비팔로워 도달의 핵심 신호다.
  - 2026-04-30부터 사진·캐러셀도 원본이어야 추천에 노출된다.
  - 해시태그는 게시물당 5개가 상한이다.
  - 캡션이 구글에 색인된다.
  - 캐러셀만으로는 비팔로워 도달이 약하니 15초 릴스를 같이 올린다.
- **규제**:
  - 공정위 지침 2024-12-01 시행분에 2025-12-02 안내서가 더해졌다. 표시는 사진 안 또는 본문 첫 부분/첫 해시태그에, 본문과 구분되게, 더보기 뒤에 숨기지 않는다.
  - 유료 파트너십 라벨을 함께 붙인다.

- 형식별 가중치:
  - 릴스는 피드 대비 +20~50%, 스토리는 피드의 30~50%, 2차 활용권은 +30~50%(StartBucks).

- 정보형 카드뉴스는 브랜드 메시지를 슬라이드 1~2장에 녹일 수 있다. 그래서 **"기획형 콘텐츠" 단가를 피드 공식보다 높게 부를 여지**가 있다(추정, 실측 필요).

### 3-3. 직접 제안·미디어킷 관행
- 미디어킷 구성 관행([forcreator](https://forcreator.co.kr/blog/influencer-sponsorship-howto)): 소개·콘셉트 → 대표 콘텐츠 3~5개 → 지표(팔로워·평균 도달·참여율·저장/공유) → 오디언스(연령·성별·지역) → 협업 사례 → 형식·단가·연락처.
- 첫 메일·DM 관행([social-lover](https://social-lover.com/guide/influencer-collab-dm), [dangaro](https://dangaro.com/blog/sponsorship-proposal-email-guide)):
  - 300자 안에 "누구 / 왜 이 브랜드인지 / 무엇을 제안하는지(포맷 시안 1장) / 미디어킷 링크"를 담는다.
  - 2~3주 뒤 리마인드는 1회만 보낸다.
  - 수치 없는 영향력 주장, 단가 누락, 대량 발송은 실패 패턴이다.
- 성공 사례: 팔로워 약 500명인 단일 카테고리 계정이 DM을 받은 개인 후기가 있다([tilnote](https://tilnote.io/pages/683d045b3b88c1fc497d2bbf), 검증 불가).
- 가짜 협찬 DM 사기에 주의한다([forcreator](https://forcreator.co.kr/blog/fake-brand-collab-dm-scam)). 사업자 정보·공식 도메인 메일로 확인한다.

## 4. 규제·실무
- **공정위 추천·보증 심사지침**:
  - 2024-12-01 시행 개정으로 표시 문구를 **제목 또는 첫 부분**에 둔다. 첫 부분이면 글자 크기를 키우거나 색을 달리해 본문과 구분되게 한다([신김 2613](https://shinkim.com/kor/media/newsletter/2613), [i-boss 74668-1685](https://www.i-boss.co.kr/ab-74668-1685)).
  - 2025-12-02 배포된 안내서 개정본: 인스타는 **사진 안**에 표시한다. 사진과 본문이 연결돼 쉽게 인식되면 본문 첫 부분이나 **첫 번째 해시태그**에 둘 수 있다. '더보기' 같은 추가 행동이 필요하면 안 된다. 4원칙 = 접근성·명확성·인식 가능성·언어. 경품 당첨이나 우수 리뷰어 선정 같은 조건부·미래 대가도 표시 대상이다([아주경제](https://www.ajunews.com/view/20251202085042877), [뉴스서울](https://newsseoul.co.kr/news/view/1065583816365047), [inews24](https://www.inews24.com/view/1295063)).
  - 유형별 문구(관행):
    - 원고료: "광고 · ○○로부터 원고료를 받아 작성"
    - 무상 제공: "협찬 · ○○에서 제품을 무상으로 제공받음"
    - 할인: "○○로부터 할인 혜택을 받음"
    - 제휴 링크: "구매 시 수수료를 받음"
  - 영어(sponsored)·은어·모호한 해시태그만으로 대신하면 안 된다([lawtalk](https://www.lawtalk.co.kr/posts/163377)).
  - **우리 운영안**: ① 1장 우하단에 "광고 · ○○ 제공"(본문과 같거나 더 큰 글자) ② 캡션 첫 줄에 같은 문구 ③ 유료 파트너십 라벨. 세 가지를 모두 쓴다.
- **유료 파트너십 라벨**:
  - 프로페셔널 계정에서 게시 직전 고급 설정 → "유료 파트너십 라벨 추가" → 브랜드 파트너를 검색해 지정한다. 브랜드가 승인하면 브랜드가 게시물 광고(부스트)를 집행할 수 있다.
  - 라벨만으로는 공정위 표시를 대신하지 못한다(사진·첫 줄 표시 병행)([pathsocial](https://www.pathsocial.com/ko/resources/instagram-paid-partnership-landing-your-dream-brand-deal/)).
- **세금(전문가 확인 필요)**:
  - 사업자 없이 원고료를 받으면 3.3% 원천징수 사업소득이 되고, 이듬해 5월 종합소득세를 신고한다.
  - 사업자를 등록할 때 인적·물적 시설이 없는 1인 창작자는 면세 940306, 장비·인력을 갖추면 과세 921505로 나뉜다. 과세라면 간이과세 요건을 검토한다.
  - 제품 협찬도 원칙상 소득이다([택스워치](https://www.taxwatch.co.kr/article/tax/2023/09/19/0001), [StartBucks](https://www.startbucks.co.kr/post.html?slug=instagram-sponsorship-rate-guide)).
  - **KE Studio가 이미 사업자인지, 업종을 추가할지 세무사 확인이 필요하다.**
- **금지 품목 규제(한 줄씩)**:
  - 건강(건기식·다이어트): 식품표시광고법상 질병 예방·치료 표방 금지, 자율심의 대상. SNS 부당광고 적발이 2025-08 기준 5,214건([뉴시스 2025-08-22](https://www.newsis.com/view/NISX20250822_0003300195)).
  - 금융: 금융소비자보호법상 인플루언서 광고는 판매업자의 확인을 받아야 한다. 2026년 핀플루언서 규제 강화 법안이 추진 중이다([헤럴드 2026-02-24](https://www.heraldk.com/article/2026022421072124622)).
  - 법률: 변호사 광고는 변호사법과 대한변협 광고규정 적용 대상이라 개인 계정 협찬 부적합(추정, 원문 미확인).
  - 도박: 불법 도박 사이트 홍보는 국민체육진흥법상 3년 이하 징역 또는 3천만원 이하 벌금([대륜](https://www.daeryunlaw.com/faq/detail/705)).
  - 주류: 국민건강증진법 제8조의2에 따라 음주 유도 금지, 경고 문구 필수. 2026-08 OB맥주 시정 사례([이코노미스트 2026-08-20](https://economist.co.kr/article/view/ecn202608200025)).
