대표 지정 계정(@_trend_kr, @ai.trend.kr, @trend_portal)을 맨 위에 두고 가장 먼저 분석했다.

## 확인 방법과 한계 (먼저 읽기)
- **팔로워 수**: 인스타 프로필 og:description과 공개 embed(contextJSON)로 2026-10-02에 직접 받은 값이다. 숫자는 바뀌므로 (추정)으로 본다.
- **✔ 직접 관찰**: 공개 게시물 이미지와 캡션을 직접 내려받아 봤다. 해당 계정은 @ai.trend.kr, @_trend_kr, @cultureart4u(각각 18~36장)와 여행·음식 12계정(캐러셀 2개씩, 표지·2장·마지막 장)이다. 이미지는 스크래치패드에만 받았고 저장소에는 넣지 않았다(저작권). 이 문서에는 링크만 둔다.
- **△ 추정**: 기사·소개 페이지·바이오만으로 쓴 칸이다. 표에 △로 표시했다.
- **@trend_portal은 확인 불가**: 공개 embed 응답이 일부러 넣은 가짜 핸들과 같았고, 웹·Threads 검색에도 나오지 않는다. 존재하지 않거나 비공개 또는 정지된 계정으로 보인다. 비슷한 @trendportal(팔로워 약 1천)은 다른 계정이라 제외했다. **대표가 올바른 핸들을 알려 주면 다시 분석한다.** 그래서 레이아웃 3안 가운데 2안은 지정 계정 @ai.trend.kr과 @_trend_kr에서 골랐다.
- 언론사·공공·대기업 공식 계정은 4개(@_trend_kr 인터넷신문, @_tripgoing 여행 미디어, @visitjeju.kr, @nationalmuseumofkorea)로 상한 5개 안이다.
- 원래 요청된 `cardnews/docs/DESIGN_SOURCES.md`는 브랜치에 없어서 읽지 못했다. 진단은 지시문과 contact.png(2판)로 대신했다.

### 23계정 공통 패턴 (✔ 관찰 기반)
1. **표지는 사진 + 2줄**: 설정줄과 펀치줄로 나뉜다. 매거진형은 ~다·명사형으로 15~25자, 큐레이션·커뮤니티형은 질문·감탄 "?!"을 쓴다. "1단계 · 준비물" 같은 템플릿 제목을 쓰는 계정은 없다.
2. **본문 장 제목은 그 장의 결론 한 줄**(@ai.trend.kr)이거나 "\| 소제목"(@_trend_kr)이다. 본문은 1~4줄.
3. **마지막 장은 세 갈래**: ① 팔로우 카드(@ai.trend.kr, @_trend_kr, @_tripgoing, @heypop_official) ② 정리·CTA 카드(@cultureart4u, @datepop) ③ CTA 없이 끝내고 캡션에서 마무리(@daytripkorea).
4. **출처는 정형 한 줄**: 📸/Source/이미지 제공 ・ 출처. 장 안 소자로 넣거나 캡션 끝에 둔다.
5. **사진은 한국 현장**: 한국 매장·거리·전시장 실사다. 서양 스톡 정물만으로 된 세트는 없었다. 세트 11 2판의 진단 ①을 뒷받침한다.
