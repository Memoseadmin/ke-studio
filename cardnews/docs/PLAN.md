# 카드뉴스 프로젝트 — 기획 (v1, 2026-10-01, 대표 결정으로 분리)

## 한 줄
인스타그램 **한국어 카드뉴스(캐러셀)** 계정을 키우고, **한국 브랜드 제휴·협찬 광고 게시물 수익**을 목표로 한다(2026-10-01 대표 결정: 한국 제휴 광고 중심). Korea Explained의 소재·비주얼은 한국 독자용으로 재구성해 재활용한다. 본 채널(유튜브)과는 별도 프로젝트·별도 폴더·별도 브랜치로 운영하되, **관리는 COO 세션 하나가 통합**한다(docs/PROJECTS.md).

## 수익 목표와 게이트
- 주 수익 = 한국 브랜드 협찬·광고 게시물(브랜드 제휴 콘텐츠, 건당 단가). 보조 = 프로필 링크 허브의 쿠팡파트너스 링크(지정 고지 문구 그대로, 서브ID `ig-<post>`).
- **게이트 C1(첫 90일)**: 팔로워 2,000 + 평균 저장률(저장/도달) 3% 이상 + 미디어킷 완성 + 첫 협찬 문의 또는 제안 발송 5건. 월 비용 5만원 이하(KE 전체 상한 20만원 안에서 배정).
- 게이트 C2(6개월): 팔로워 1만 + 첫 유료 협찬 1건(건당 단가는 미디어킷에서 추정치로 시작, 실측으로 교체).
- 60일 시점 중간 판단: 저장률·팔로워 증가가 안 나오면 포맷(장수·톤·언어)을 바꾼다.

## 대상·언어 (대표 확정 2026-10-01)
- **KR 계정 1개**(한국 독자). 협찬 후보 = 편의점·식품 신제품, 문구·공예 키트, 지역 축제·관광공사, 한국어·교양 교육 앱, 여행 플랫폼, 생활용품. 제외 = 건강·금융·법률·도박·주류.
- EN 계정은 하지 않는다(본 채널 숏폼 재게시도 KR 캡션으로만).

## 콘텐츠
- 형식: 캐러셀 7장(1장 훅 → 5장 본문 → 7장 CTA/출처). 하루 1개, 첫 14일은 테스트. 릴스는 본 채널 숏폼을 그대로 재게시(추가 제작 없음).
- 소재 30% = 본 채널 에피소드 사실을 한국 독자용 "알고 보면" 각도로 재구성, 70% = 한국 주간 트렌드(네이버·한국 뉴스·커뮤니티·인스타 해시태그, 건강·금융·법률·정치·실존 인물 비판 제외). 형식은 한국 카드뉴스 관행(정보 요약·체크리스트·비교표).
- 비주얼 = 본 채널 디자인 시스템(민화 플랫 × 한지 질감, 색 토큰·폰트 동일). 실존 인물 얼굴·로고·드라마 스틸 금지. 모든 수치에 출처 1줄(7장).
- 톤: 담백한 존댓말, 과장·낚시 금지. 매 게시물 AI 생성물 표시(캡션 끝 1줄 "이미지·초안은 AI로 생성, 사실 확인은 사람이 했습니다" — 사람 검수는 대표 PR 승인으로 기록).

## 협찬 규칙 (legal-reviewer 체크리스트)
- 유료 협찬은 인스타그램 "유료 파트너십 라벨" + 캡션 **첫 줄** "#광고" 또는 "광고 · OO 제공"(공정위 추천·보증 심사지침: 게시물 첫 부분, 본문과 같은 글자 크기, 더보기 뒤에 숨기지 않음). 쿠팡 링크 게시물은 지정 고지 문구를 캡션 첫 줄에.
- 협찬 계약서는 legal-reviewer가 조항별 검토(`cardnews/contracts/`). 건강·금융·법률 상품 협찬 금지. 브랜드 로고는 협찬 게시물에서만, 계약서에 사용 허락 조항 있을 때만.
- 미디어킷(`cardnews/docs/MEDIA_KIT.md`, 한국어): 팔로워·도달·저장률·연령·성별 실측 + 게시물 단가표(추정치 표시) + 금지 품목 + 협찬 진행 절차(제안→초안 PR→승인→게시→성과 보고).

## 운영
- 게시: 인스타그램 비즈니스 계정 + Meta Graph API 예약 게시(환경변수 `IG_ACCESS_TOKEN`, `IG_USER_ID`, 이름만 docs/ENV.md). API 전까지는 수동 게시 패키지(`cardnews/posts/YYYY-MM-DD/` 이미지 7장 + caption.txt).
- 측정(analyst): 주간 팔로워·도달·저장·공유·프로필 클릭·링크 허브 클릭 → `cardnews/reports/`. 본 채널 reports와 분리.
- 사람 몫(대표): 게시물 PR 승인(approved 라벨, 본 채널과 동일 절차), 협찬 수락 결정, 계약 서명.

## 본 채널과의 경계
- 브랜치: 이 프로젝트 산출물·문서는 **`cardnews/main`** 에만 커밋(COO는 `.worktrees/cardnews`에서 작업). 루트 `docs/`는 작업 브랜치, `episodes/`는 `ep/EPxxx`에만 커밋해 브랜치가 섞이지 않게 한다.
- 공용: `.claude/agents/`·`.claude/skills/`·디자인 시스템·CLAUDE.md 규범. 변경이 필요하면 본 채널 HANDOFF "대표 결정 대기"에 올린다.
