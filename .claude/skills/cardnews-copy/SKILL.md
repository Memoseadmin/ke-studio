# cardnews-copy v1.1 (사내 작성, 근거 cardnews/docs/BENCHMARK.md)

## 1. 표지 훅 5종 (2줄 = 설정줄 + 펀치줄, 펀치줄 ≤10자)
| 공식 | 예시 | 근거 |
|---|---|---|
| 숫자 대비 | "필사 +692.8%" | 점수는 위, 비용은 절반[^a] |
| 질문 | "왜 다들 베껴 쓸까?" | GPT 또 새 모델?[^a] / 공짜? 안 갈 이유 없잖아[^p] |
| 반전 | "윤동주도 베껴 썼다" | 5분 말하고 잤는데, 일어나 보니[^a] |
| ~인 줄 알았는데 | "숙제인 줄 알았는데" | 단순한 탄광마을이 아닙니다[^t] |
| 체크리스트 예고 | "필사 입문 5칸" | 이 5개만 알면 ~ 한번에 끝[^a] / ○○ 27곳 총정리[^s] |
- 표지는 사건·결과를 먼저 말한다("~한다/~했다" 뉴스형[^k], 또는 "~해요"). 내용을 다 말하지 않는다[^g].

## 2. 한 장 한 메시지
- 제목 ≤12자, 본문 ≤2문장·≤45자. 장 번호(1, 2…)를 제목 위에[^a].
- 제목은 그 장의 결론. 대비("발표 25개, 핵심은 딱 3개"[^a])나 독자 질문("그래서 언제 쓸 수 있죠?"[^a])으로.
- 핵심어 1개만 굵게 또는 포인트색[^a][^c].
- C 틀(@cultureart4u, 3:4, 띠 폭 904px)은 제목 대신 굵은 첫 줄 ≤14자, 본문 ≤60자·≤2문장(줄당 ≤21자 × 3줄), 표지 설정줄 ≤13자, 펀치줄 ≤10자. 영양소 기준(§8) 때문에 본문 상한을 45→60자로 올렸다. 글자 수는 폰트 크기 기준 추정치, 렌더로 확인.

## 3. 8장 서사
1 훅 → 2 왜 지금(수치·계기) → 3~6 본론 4장(장마다 하나) → 7 정리(체크리스트·한 줄 요약) → 8 독자에게 묻기 + 출처 + 계정 사인오프[^a][^k][^h].

## 4. 문체
- 구어. 종결어미를 섞는다: ~요 / ~죠 / ~거든요 / ~고요 / ~다 / 명사 종결[^a][^c]. 같은 어미 3장 연속 금지, "~합니다" 2문장 연속 금지.
- 설명문 금지: "A는 B입니다" 정의형 대신 장면·대비·숫자로.
- 화자 1인칭 허용("책가도가 골라 봤어요")[^a][^h].
- AI 티 표현 금지 20 (벤치마크 카드 본문에 안 나옴. '지금 바로'는 링크 CTA에서만 관찰[^a]): 저장해 두고 꺼내 보세요 / ~하는 방법 / 지금 바로 / 알아볼까요 / 함께 알아봐요 / 꿀팁 대방출 / 완벽 가이드 / ~의 모든 것 / 다양한 / 효과적인 / 중요합니다 / 인사이트 / 여러분의 일상에 / ~의 세계로 / 소개합니다 / 도움이 되셨나요 / 결론적으로 / 이처럼 / 한 걸음 더 / 시작해 보세요.
  (저장 유도는 상황을 붙일 때만: "회 먹을 땐 꼭 이렇게"[^k], "이번 달 안에 하나씩"[^d].)

## 5. 숫자·출처
- 수치는 원문 그대로(692.8%를 "8배"로 바꾸지 않음), 기준 연도·기관을 같은 장에.
- 추정치는 "(추정)". 출처는 8장 + 캡션 끝 "📸/출처 ・ 매체 날짜"[^k][^t]. 사진·그림은 "이미지 제공 ・"[^c].

## 6. 금지
건강·금융·법률, 과장("역대급·미친" — 벤치마크엔 있으나[^a][^c] 도록 톤과 안 맞아 금지), 실존 인물 사진, 출처 없는 비교급.

## 7. 자가 점검 10
1 표지 펀치줄 ≤10자·5종 중 하나 2 제목 ≤12자 3 본문 ≤2문장·≤45자 4 장마다 메시지 1개 5 8장 서사 순서 6 같은 어미 3연속 없음 7 금지 표현 0개 8 모든 수치에 기관·연도 9 새 사실엔 출처 URL 10 금지 주제·과장 0. 11 영양소 기준(§8) 충족표 첨부.


## 8. 영양소 기준 (v1.1 추가, 대표 결정 2026-10-02 "내용이 너무 부실하다")
- **장마다 새 사실 1개 + 출처**: 캐러셀 1~7장 각 1개. 앞 장에 없던, 확인 가능한 사실. 출처는 장 안 소자("출처 ・ 매체 날짜") 또는 8장 묶음 + facts.md URL.
- **세트당 인용·일화 2개 이상**: 실존 인물의 기록된 말·행동(예: 윤동주가 백석 『사슴』을 필사), 1차 출처.
- **세트당 수치 3개 이상**: 서로 다른 수치, 기관·연도를 같은 장에.
- 실천 제안("노트 한 권이면 충분")은 사실이 아니다. 요령 장에는 요령을 뒷받침하는 사실(조사·연구·역사 일화)을 붙인다. 요령만 있는 장 = 0.
- 사실 원장 = 세트 폴더 `facts.md`(사실 / 수치 / 매체·날짜 / URL). 캡션·릴스·스토리는 이 원장의 부분집합만 쓴다.
- 축소판: 릴스 수치 ≥2·인용·일화 ≥1 / 스토리 사실 ≥1·수치 ≥1.

사실 밀도 점검표(산출물 끝에 첨부):
| 장 | 새 사실(한 줄) | 유형(수치/인용/일화/사실) | 출처(매체·날짜·URL) | 앞 장 중복 |
|---|---|---|---|---|
| 1~7 | | | | 없음 |
| 합계 | 새 사실 n/7 | 인용·일화 n(≥2) · 수치 n(≥3) | 미검증 0 | 중복 0 |
