# ke-visual-critique v1 (근거 CREATIVE_AGENTS §4-2, A3·A4·A5)

## 1. 루브릭 30항 (각 0~10, 해당 없으면 N/A)
**사진 배치 P**: ①장 내용과 사진 사물이 1:1 일치 ②주인공 1개가 3초 안에 보임 ③시선 흐름(사진 속 방향→글 띠) ④크롭이 피사체 중심, 핵심 디테일 안 잘림 ⑤원화 위 본문 0 ⑥한국 실물(서양 스톡 금지) ⑦톤 프리셋 일관(DS §9-2) ⑧장 간 구성 변주(3연속 금지) ⑨실물↔원화 비교가 있으면 같은 스케일 ⑩출처 소자 가독(360px).
**타이포 T**: ①제목/본문/출처 3단 위계 ②360px에서 본문 판독 ③한 줄 글자 수 규칙 ④어절 단위 줄바꿈(조사 고아 금지) ⑤강조색 1곳 ⑥서체 2종 이하 ⑦자간·행간 DS 값 ⑧숫자는 크게(수치 3개) ⑨한글을 그림처럼 쓰는 장 1개(표지) ⑩AI틱 문구 0(copy-editor 판정 인용).
**모션 M**: ①0~2초에 주인공·훅 ②줌 문법(디테일↔전체) ③컷 길이 변주(같은 길이 3연속 금지) ④움직임 이유가 내용에 있음 ⑤이징 일관 ⑥자막 무음 판독 ⑦원화 변형 0(크롭·팬·줌만) ⑧질감(그레인·종이) 일관 ⑨마지막 1초 CTA·출처 ⑩음악·효과음 상용 라이선스 기록.

## 2. 절차·통과선(A4)
컨택트시트·360px본 직접 열기 → 점수+근거 → AI틱 감점(서양 스톡·흰 박스 반복·같은 틀 3연속·매끈한 그라데이션·출처 없는 그림) → N/A 제외 **평균 ≥7 그리고 최저 ≥6** = 통과, 아니면 반려.

## 3. 서식 `CRITIQUE-vN.md`
```
# CRITIQUE-vN · <세트> · 날짜 · 루프 1/2
| 항목 | 점수 | 근거 1줄 |  (30행)
평균 · 최저(항목) · 판정
## 반려 사유 (직원별)
## 선택 기록
## 잘된 점 3
## 추정
```
반려 사유 = `항목 번호 · 문제 · 누가 · 어떻게 1줄`. 예 `[photo-editor] P4 · 3장 붓끝 잘림 · y −120px`.

## 4. best-of-4 선택 기록 (A5)
```
| 장 | 페르소나 | 시드4 | 선택 | 이유(번호) | 탈락 사유 |
```
사진 최종 크롭도 같은 표로.

## 5. 루프 규칙 (A3)
반려 → 제작 직원 수정 → 재제출, 최대 2회. 대표 PR엔 통과본+점수표만. 2회 뒤 반려면 COO에 보고. 결정 필요 시 기본값+"추정" 기록, 멈추지 않는다.
